# Low & Slow: Entra ID Initial Access — Attack & Defend Workshop

Workshop práctico sobre cómo un operador de Red Team investiga rutas de initial access en Microsoft Entra ID y cómo Blue Team puede reconstruir, detectar y responder a esa misma actividad.

El taller sigue una cadena operacional: comenzar con reconnaissance sin autenticación, validar una hipótesis de credenciales con el mínimo volumen necesario y, después, probar los límites reales de MFA y Conditional Access. Cada fase ofensiva termina observando la telemetría que recibió el defensor.

## ¿Para quién es este workshop?

- **Red Teamers y operadores ofensivos** que evalúan identity attack paths en entornos Microsoft cloud.
- **Blue Teamers, SOC analysts y threat hunters** responsables de investigar actividad de autenticación en Entra ID.
- **Detection engineers** que necesitan convertir comportamiento ofensivo reproducible en hunting queries y analytics
